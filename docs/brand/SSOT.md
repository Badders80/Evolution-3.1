# Evolution Stables - Single Source of Truth (SSOT)

This document serves as the definitive reference for Evolution Stables brand, business model, and technical requirements.

## Core Identity
- **Brand Name:** Evolution Stables
- **Philosophy:** "Understated Authority" - Intersection of racing heritage and digital infrastructure.
- **Tone:** Declarative, confident, calm. No hype.
- **Language:** British English (colour, modernise, etc.).

## Visual Identity
- **Gold:** `#D4AF37`
- **Black:** `#000000`
- **White:** `#FFFFFF`
- **Typography:** Audi-inspired (300/400/600 weights).
  - Heading: Geist Sans / Playfair Display
  - Body: Geist Sans
  - Labels: Wide letter-spacing (0.1em - 0.25em)

## Technical Architecture
- **Framework:** Next.js 15 (App Router)
- **Runtime:** React 19
- **Styling:** Tailwind CSS + Shadcn/UI
- **Deployment:** Vercel (Production: main branch, Foundation: evolution-4.0-foundation)
- **Analytics:** Google Analytics 4

## Success Metrics
- **Performance:** Lighthouse >90
- **Accessibility:** WCAG 2.1 AA
- **Conversion:** Waitlist signups (Lead capture)

## Marketplace Features (Phase 2)
- **Authentication:** NextAuth (Google OAuth)
- **Database:** Supabase / Prisma (Proposed)
- **CMS:** Sanity (Proposed)
